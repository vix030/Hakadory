# Hakadory (web)

Hakadory（Windows デスクトップ版）をブラウザで動かせるようにしたものです。作業と休憩を区別して記録するストップウォッチ式のポモドーロタイマーで、計測・集計・通知・Markdown 書き出しの仕様はデスクトップ版と同じにしてあります。

デスクトップ版とは**別物として並存**させます。グローバルショートカット（他のアプリを操作中でも効くキー）はブラウザでは実現できないため、そこを必要とする使い方はデスクトップ版のままにしてください。

## 何が要るか

- 見るだけ: ブラウザ（Chrome / Edge / Firefox / Safari）
- 公開する: 静的ファイルを置ける場所（GitHub Pages など）。サーバープログラム・データベース・ログインは**不要**
- ビルド: 不要。ここにあるファイルがそのまま公開物

## 使い方（ローカルで開く）

`index.html` をダブルクリックしても動きますが、`file://` ではサービスワーカーが登録されず、ミニ表示（ピクチャーインピクチャー）も動きません。次のようにローカルサーバー経由で開いてください。

```
py -m http.server 8000
```

（このフォルダで実行します。別の場所から実行する場合は `--directory <このフォルダ>` を付けてください。）

ブラウザで `http://localhost:8000/` を開きます。

## 公開する（GitHub Pages）

1. このリポジトリを GitHub に push する
2. GitHub のリポジトリページ → **Settings** → **Pages**
3. **Source** を `Deploy from a branch`、**Branch** を `main`（または公開したいブランチ）と `/ (root)` にして **Save**
4. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

HTTPS は自動で付きます。ピクチャーインピクチャー・サービスワーカー・画面ロック防止はいずれも HTTPS（または `localhost`）でしか動かないため、この経路で公開するのが前提です。

**注意**: GitHub Pages はリポジトリ全体を公開します。このリポジトリには web 版のファイルしか置かない前提です。公開したくないものを同じリポジトリに入れないでください。

## インストールする（PWA）

公開した URL を Chrome / Edge で開くと、アドレスバーにインストールのアイコンが出ます。インストールすると独立したウィンドウとアイコンで起動でき、タスクバーにも置けます。オフラインでも開けます。

## デスクトップ版との違い

| 項目 | デスクトップ版 | web 版 |
| --- | --- | --- |
| グローバルショートカット | あり | **なし**（ブラウザは他アプリ操作中のキーを受け取れない） |
| ウィンドウ内のキー操作 | `Space` `W` `B` `L` `M` `Ctrl+Z` `Ctrl+Y` | 同じ |
| ラップの手直し | 一覧の行を右クリック | 一覧の行を押す（画面下から手直しシートが出る） |
| 確定ラップのメモの編集 | 右クリックメニューの「メモを編集」（別ウィンドウ） | 手直しシートの「メモ」欄 |
| ミニ表示 | 常に最前面の小ウィンドウ | ピクチャーインピクチャーの小窓（Chrome / Edge）。非対応ブラウザでは画面内で縮小 |
| 常に最前面 | 設定で切替 | ミニ表示が常に最前面。代わりに「画面を消さない」を用意 |
| 設定の保存先 | `Hakadory.settings.json` | ブラウザの localStorage |
| `.md` 書き出し | 保存先を選ぶダイアログ | ダウンロード |
| 記録の保持 | アプリを閉じると消える | タブを閉じても復元する（下記） |
| 自動開始・自動終了 | アプリ起動中のみ | ページを開いている間のみ |
| 通知音 | Windows のシステム音 | ブラウザで合成した音。最初に一度どこかを押すまで鳴らない |

### ラップの手直し

ボタンの押し間違いは、あとから直せます。**どの操作でも総時間は減りません**。時間は結合した相手のラップに移るだけです。

ラップ一覧の行を押すと、画面下から手直しシートが出ます（スマートフォンでも押しやすいよう、右クリックではなくタップで開きます）。

| 操作 | 内容 |
| --- | --- |
| 種別を変える | そのラップの種別だけを差し替える。長さは変わらない |
| 前のラップと結合 | そのラップを 1 つ上に畳む。種別と開始時刻は前のラップのものになる |
| 次のラップと結合 | そのラップを 1 つ下に畳む。いちばん下のラップは、進行中のラップの先頭に戻る |

結合先の種別がボタンに出るので（「前のラップ（作業）と結合」など）、時間がどちらに移るか押す前に分かります。押し間違えて押し直したときにできる短いラップは「次のラップと結合」で消せます。前後が同じ種別のときは、2 回結合すると 3 本が 1 本にまとまります。

進行中のラップは、大きい時計の上の見出し（「作業 ・ 計測中」など）を押すと同じシートが開きます。種別を選べばラップを切らずに差し替わり、「前のラップと結合」は進行中のラップを直前のラップに畳みます（種別も前のものに戻ります）。

### ラップのメモ

大きい時計の下の「メモ」に書いた内容は、**次のラップを押した時点でそのラップに残ります**（入力欄は空に戻ります）。書くのは常に進行中のラップについてで、確定してから思い出して書くより、作業中に書き足せるほうが実際の使い方に合うためこの形にしています。

- 確定したラップのメモは、一覧の行を押して開く手直しシートの「メモ」から直せる。書いた内容はシートを閉じた時点で残る（種別の変更・結合を押したときも、先に書き戻す）
- 結合すると両方のメモが `" / "` でつながる（時系列順。どちらも捨てない）
- メモの編集も `Ctrl+Z` で戻せる（控えに進行中のメモも含めている）
- 一覧の「メモ」列と `.md` 書き出しの表に入る。書き出しでは表を壊さないよう `|` だけ `\|` に置き換える
- 前後の空白は落とす。リセットで進行中のメモも消える

デスクトップ版と同じ仕様です（デスクトップ版はシートではなく、行の右クリックメニューの「メモを編集」から直します）。

### 元に戻す・やり直す

ラップ操作は `Ctrl+Z` で順に取り消せます。戻しすぎたら `Ctrl+Y`（`Ctrl+Shift+Z` も同じ）です。**スマートフォンにはキーが無いので、手直しシートの下にも同じボタンを置いています。**

- ラップの確定、種別の変更、結合、メモの編集のどれでも戻せる。直前の 1 手だけでなく、遡って何度でも戻せる（上限 50 手）
- 戻しても計測は止まらず、総時間も変わらない。**戻している間に経った時間も失われない**（確定ラップの合計が変わったぶんを進行中のラップで相殺しているため）
- 「リセット」は戻せない（総時間や計測開始時刻までは控えていないため）

「通過」と種別ごとの合計は保存せず、そのつどラップから数え直します。手直ししても積算はずれず、localStorage から復元したときも合計はラップから数え直します。

### 記録の保持

タブを誤って閉じても続きから使えるよう、計測状態とラップを 15 秒ごとに localStorage へ保存し、次に開いたときに復元します。**閉じている間も計測は進んでいたものとして加算します**（計測中に閉じた場合）。区切りたい場合は閉じる前に一時停止するか、`.md` に書き出してからリセットしてください。

### 時間の数え方

経過時間は「開始した時刻との差」で毎回計算しているため、タブが裏に回ってブラウザがタイマーを間引いても値はずれません。表示の更新だけが粗くなります。

通知音は、鳴らす時刻が近づいたぶんを Web Audio 側の時計に先に渡しておきます。再生を受け持つのは JS のタイマーではないため、裏タブで `setInterval` が間引かれても時刻どおりに鳴ります。渡したあとに一時停止・種別の切り替え・設定変更があれば取り消します。

iPhone / iPad の Safari は裏に回ると AudioContext ごと止めるため、そこだけは表に戻したときに 1 回鳴る形になります。

| `test_Hakadory.py` | スモークテスト。`py test_Hakadory.py` |

### アイコンを作り直す

図柄の定義はデスクトップ版の `make_icon.py` 1 か所だけに置いています。web 版は別リポジトリになったため、その場所を次の順で探します。

1. コマンドライン引数
2. 環境変数 `HAKADORY_DESKTOP_DIR`
3. 既定値 `../02_MADEbyGPT/Hakadory`（このフォルダからの相対）

```
py make_icons.py
py make_icons.py ..\02_MADEbyGPT\Hakadory
```

デスクトップ版が手元にない場合、アイコンは生成できません（生成済みの `icon-*.png` はこのリポジトリに入っているので、図柄を変えないかぎり実行は不要です）。

## セキュリティとプライバシー

- **サーバーへは何も送らない**。計測記録も設定もブラウザの中（localStorage）だけに残る
- **外部ホストを自動では読み込まない**。CDN のフォント・スクリプト・解析タグを使っていない（テストで検査している）
- 唯一の外部 URL が報告フォームへのリンク（下記）。**押したときだけ別タブで開く**もので、ページを見ただけでは外部に何も出ない。テストはこの 1 件だけを例外として通し、それ以外の外部 URL が混ざれば落ちる
- 記録はブラウザに残るため、**共用 PC では使わない**か、使用後に「リセット」してブラウザのサイトデータを消す
- localStorage はブラウザのデータ削除で消える。長く残したい記録は `.md` に書き出す
- 公開する URL は誰でも開ける。**開いた人ごとに記録は独立している**（他人の記録は見えない）

この節を正本とします。

### 要望・不具合の報告

アプリ内（「使い方」タブと「設定」タブ）から Google フォームへリンクしています。行き先は `app.js` の `FEEDBACK_URL` 1 か所だけで決まり、**空文字にすると両方のリンクが隠れます**（行き先の無いリンクを出さないため）。

自前の受け口を持たないのは、そのためだけにサーバーとプライバシーポリシーを抱えたくないからです。フォームなら回答者にアカウントを求めず、送信は Google 側で完結し、このアプリのコードは静的ファイルのままでいられます。**アプリの記録や設定が自動で送られることはありません**。送られるのはフォームに書いた内容だけです。
