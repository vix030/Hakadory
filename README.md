# Hakadory (web)

作業と休憩を区別して記録するストップウォッチで、計測・集計・通知・Markdown 書き出しもできます。


## 何が要るか

- 見るだけ: ブラウザ（Chrome / Edge / Firefox / Safari）
- 公開する: 静的ファイルを置ける場所（GitHub Pages など）。サーバープログラム・データベース・ログインは**不要**
- ビルド: 不要。ここにあるファイルがそのまま公開物

## 使い方（ローカルで開く）

`index.html` をダブルクリックしても動きますが、`file://` ではサービスワーカーが登録されず、ミニ表示（ピクチャーインピクチャー）も動きません。次のようにローカルサーバー経由で開いてください。

```
py -m http.server 8000
```

（このフォルダで実行します。別の場所から実行する場合は `--directory <このフォルダ>` を付けてください。）

ブラウザで `http://localhost:8000/` を開きます。

## 公開する（GitHub Pages）

1. このリポジトリを GitHub に push する
2. GitHub のリポジトリページ → **Settings** → **Pages**
3. **Source** を `Deploy from a branch`、**Branch** を `main`（または公開したいブランチ）と `/ (root)` にして **Save**
4. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

HTTPS は自動で付きます。ピクチャーインピクチャー・サービスワーカー・画面ロック防止はいずれも HTTPS（または `localhost`）でしか動かないため、この経路で公開するのが前提です。

**注意**: GitHub Pages はリポジトリ全体を公開します。このリポジトリには web 版のファイルしか置かない前提です。公開したくないものを同じリポジトリに入れないでください。

## インストールする（PWA）

公開した URL を Chrome / Edge で開くと、アドレスバーにインストールのアイコンが出ます。インストールすると独立したウィンドウとアイコンで起動でき、タスクバーにも置けます。オフラインでも開けます。

## デスクトップ版との違い

| 項目 | デスクトップ版 | web 版 |
| --- | --- | --- |
| グローバルショートカット | あり | **なし**（ブラウザは他アプリ操作中のキーを受け取れない） |
| ウィンドウ内のキー操作 | `Space` `W` `B` `L` `M` | 同じ |
| ミニ表示 | 常に最前面の小ウィンドウ | ピクチャーインピクチャーの小窓（Chrome / Edge）。非対応ブラウザでは画面内で縮小 |
| 常に最前面 | 設定で切替 | ミニ表示が常に最前面。代わりに「画面を消さない」を用意 |
| 設定の保存先 | `Hakadory.settings.json` | ブラウザの localStorage |
| `.md` 書き出し | 保存先を選ぶダイアログ | ダウンロード |
| 記録の保持 | アプリを閉じると消える | タブを閉じても復元する（下記） |
| 自動開始・自動終了 | アプリ起動中のみ | ページを開いている間のみ |
| 通知音 | Windows のシステム音 | ブラウザで合成した音。最初に一度どこかを押すまで鳴らない |

### 記録の保持

タブを誤って閉じても続きから使えるよう、計測状態とラップを 15 秒ごとに localStorage へ保存し、次に開いたときに復元します。**閉じている間も計測は進んでいたものとして加算します**（計測中に閉じた場合）。区切りたい場合は閉じる前に一時停止するか、`.md` に書き出してからリセットしてください。

### 時間の数え方

経過時間は「開始した時刻との差」で毎回計算しているため、タブが裏に回ってブラウザがタイマーを間引いても値はずれません。表示の更新だけが粗くなります。

通知音は、タブが裏にある間は鳴らないことがあります。その場合、表に戻したときに 1 回だけ鳴ります。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | 配色（3 種）と見た目 |
| `app.js` | 計測・集計・通知・書き出し・設定の保存 |
| `manifest.webmanifest` | PWA としてインストールするための情報 |
| `sw.js` | サービスワーカー。オフラインで開けるようにする（ネットワーク優先） |
| `icon-*.png` | アイコン。デスクトップ版と同じ図柄 |
| `make_icons.py` | アイコンを生成する（図柄を変えたいときだけ実行。デスクトップ版の `make_icon.py` の描画を読み込む。下記参照） |
| `test_Hakadory.py` | スモークテスト。`py test_Hakadory.py` |

### アイコンを作り直す

図柄の定義はデスクトップ版の `make_icon.py` 1 か所だけに置いています。web 版は別リポジトリになったため、その場所を次の順で探します。

1. コマンドライン引数
2. 環境変数 `HAKADORY_DESKTOP_DIR`
3. 既定値 `../02_MADEbyGPT/Hakadory`（このフォルダからの相対）

```
py make_icons.py
py make_icons.py ..\02_MADEbyGPT\Hakadory
```

デスクトップ版が手元にない場合、アイコンは生成できません（生成済みの `icon-*.png` はこのリポジトリに入っているので、図柄を変えないかぎり実行は不要です）。

## セキュリティとプライバシー

- **サーバーへは何も送らない**。計測記録も設定もブラウザの中（localStorage）だけに残る
- **外部ホストを一切参照しない**。CDN のフォント・スクリプト・解析タグを使っていない（テストで検査している）
- 記録はブラウザに残るため、**共用 PC では使わない**か、使用後に「リセット」してブラウザのサイトデータを消す
- localStorage はブラウザのデータ削除で消える。長く残したい記録は `.md` に書き出す
- 公開する URL は誰でも開ける。**開いた人ごとに記録は独立している**（他人の記録は見えない）
