これは何か

作業と休憩を区別して測るストップウォッチ式のポモドーロタイマーです。ラップごとに種別（作業・休憩・長休憩）を持たせ、種別ごとの合計と割合をその場で集計します。

集中状態を無理に中断せず、ポモドーロテクニックの周期を維持することを目的としています。乗っているときは続ければよく、疲れたら早めに休憩を押せばいい。通知音を鳴らしても、こちらが押すまで計測は続きます。

記録は .md に書き出せます。ブラウザの中の記録はリセットや履歴の削除で消えるので、残したい日は書き出しておいてください。

はじめかた

  1. 「開始」を押すと、作業ラップとして計測が始まります。
  2. 休憩に入るときは「休憩」、戻るときは「作業」を押します。押した時点でそれまでのラップが確定し、新しいラップが始まります。
  3. 数えたくない時間は「一時停止」で止めます（計測中は「開始」が「一時停止」に変わります）。
  4. 終わったら「.md 書き出し」で記録を保存し、「リセット」で次に備えます。
  5. 押し間違えたら Ctrl + Z で元に戻せます。戻しすぎたら Ctrl + Y です。あとから気づいたぶんは「ラップの手直し」を見てください。

ラップの手直し

押し間違いは、ラップ一覧の行を押すと開く画面で直します。総時間は減らず、時間は結合した相手に移るだけです。

種別を変える
そのラップの種別だけを差し替えます。長さは変わりません。
前のラップと結合
そのラップを 1 つ上に畳みます。種別と開始時刻は前のラップのものになります。
次のラップと結合
そのラップを 1 つ下に畳みます。いちばん下のラップは、進行中のラップの先頭に戻ります。
  • 押し間違えて押し直したときにできる短いラップは、「次のラップと結合」で消せます。
  • 前後が同じ種別のときは、2 回結合すると 3 本が 1 本にまとまります。
  • 進行中のラップの種別は、大きい時計の上の見出し（「作業 ・ 計測中」など）を押すと、ラップを切らずに直せます。
  • その画面の「前のラップと結合」は、進行中のラップを直前のラップに畳みます。種別も前のものに戻ります。

元に戻す・やり直す

ここまでのラップ操作は Ctrl + Z で順に取り消せます。戻しすぎたら Ctrl + Y（Ctrl + Shift + Z も同じ）です。手直しの画面の下にもボタンがあるので、キーの無い端末でも使えます。

  • ラップの確定、種別の変更、結合のどれでも戻せます。直前の 1 手だけでなく、遡って何度でも戻せます。
  • 戻しても計測は止まりません。総時間も変わりません。戻している間に経った時間も、進行中のラップに残ります。
  • 「リセット」は戻せません。消す前に .md に書き出してください。

通知音（設定タブ）

  • ラップが始まってから指定した分で鳴ります。分は種別ごとに決められます。空欄や 0 のときは鳴りません。
  • 「繰り返す」を入れると、その後も一定の間隔で鳴り続けます。分を指定しなければ最初と同じ間隔です。
  • 「音声ファイルを選ぶ」で、手持ちの音（mp3 など）も通知音にできます。5MB まで、長いものは 20 秒で止まります。
  • 読み込んだ音声はこのブラウザの中に残るので、次に開いたときもそのまま使えます。「読み込んだ音を外す」で消せます。
  • ブラウザは、ページを一度も操作していないと音を出せません。「開始」を押していれば足ります。
  • 他のタブやアプリを見ている間も、時刻どおりに鳴ります。ただし iPhone / iPad の Safari は裏に回ると音そのものを止めるため、表に戻したときに 1 回鳴ります。

自動開始・自動終了（設定タブ）

  • 選んだ曜日の指定時刻に、作業ラップの開始／一時停止を自動で行います。
  • 曜日の指定は自動開始と自動終了で共通です。1 つも選んでいないと、どちらも働きません。
  • このページを開いている間だけ働きます。閉じている間の時刻は過ぎても何も起きません。

ミニ表示

  • 「ミニ表示」または M で小さな表示に切り替わります。Chrome / Edge では他のウィンドウの手前に出る小窓（ピクチャーインピクチャー）になります。
  • 非対応のブラウザでは、代わりに画面の中で縮小します。
  • 小窓からも開始・一時停止と種別の切り替えができます。「通常表示」で元に戻ります。

記録の保持

  • 計測状態とラップを 15 秒ごとにこのブラウザへ保存し、次に開いたときに復元します。
  • 計測中にタブを閉じた場合、閉じている間も計測は進んでいたものとして加算します。区切りたいときは、閉じる前に一時停止するか書き出してリセットしてください。
  • 経過時間は開始時刻との差で計算しているため、タブが裏に回っても値はずれません。表示の更新が粗くなるだけです。

保存先とプライバシー

  • 記録も設定もこのブラウザの中（localStorage）だけに残ります。読み込んだ通知音の音声ファイルだけは、大きさの都合で同じブラウザの IndexedDB に置きます。サーバーへは何も送りません。
  • 共用の PC では使わないか、使い終わったら「リセット」してブラウザのサイトデータも消してください。
  • localStorage はブラウザのデータ削除で消えます。長く残したい記録は .md に書き出してください。

要望・不具合の報告

こうしてほしい、ここが動かない、という話は報告フォームから送れます。別のタブで開きます。アカウントや名前は要りません。

動かないときは、端末とブラウザ（例: iPhone の Safari、Windows の Chrome）と、どう操作したら起きたかを添えてもらえると直しやすいです。

送られるのはフォームに書いた内容だけです。このアプリの記録や設定が自動で送られることはありません。
